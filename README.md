# 비용 생성기 자동화 시스템 - Costgenerator

## 1. 프로젝트 개요

본 프로젝트는 네이버 웍스 그룹웨어와 연동된 결재 문서 자동 생성 시스템을 구축하는 것을 목표로 합니다. ERP 데이터 연동 및 승인 프로세스 자동화를 통해 업무 효율성과 정확성을 향상시키는 데 중점을 두고 있습니다. 사용자가 엑셀 파일을 업로드하면, 응용프로그램이 네이버 웍스에 결재 문서를 자동 생성하고, 네이버 웍스와 ERP 사이에 위치한 NET REST API 서버를 통해 승인 상태를 확인하며, 승인 완료 시 REST API 서버에서 ERP 데이터를 반영합니다. 특히, `workAPI_processing.py` 파일에서 네이버 웍스 API 연동을 위한 JWT 생성 및 OAuth2 토큰 요청, 결재 문서 생성 등의 핵심 기능을 구현하고 있습니다.

## 2. 프로젝트 목표

* **네이버 웍스 그룹웨어 연동:** 네이버 웍스 경영지원 API를 활용하여 결재 문서 자동 생성 및 승인 상태 추적 기능을 구현합니다. `workAPI_processing.py` 파일에서 JWT 생성 및 OAuth2 토큰 요청을 통해 API 연동을 처리합니다.
* **ERP 데이터 연동 및 자동화:** ERP 시스템과의 데이터 연동을 통해 결재 문서 생성에 필요한 데이터를 자동으로 가져오고, 승인 완료 시 ERP 데이터를 자동으로 업데이트합니다. `data_processing.py` 파일에서 Oracle DB와의 연동을 통해 ERP 데이터를 조회하고 업데이트합니다.
* **승인 프로세스 자동화:** 네이버 웍스 결재 문서 생성부터 승인 상태 확인, ERP 데이터 업데이트까지의 전 과정을 자동화하여 업무 효율성을 극대화합니다. `workAPI_processing.py` 파일에서 결재 문서 생성 및 승인 상태 확인을 처리합니다.
* **업무 효율성 및 정확성 향상:** 수작업으로 진행되던 결재 문서 작성 및 승인 프로세스를 자동화하여 업무 처리 시간을 단축하고, 데이터 입력 오류를 최소화합니다.
* **사용자 편의성 증대:** 엑셀 파일 업로드만으로 결재 문서 생성이 가능하도록 하여 사용자 편의성을 높입니다. `costgenerator.py` 파일에서 사용자 인터페이스(UI)를 통해 엑셀 파일 업로드 및 데이터 처리를 제공합니다.

## 3. 주요 기능

* **Excel 기반 데이터 처리:** 사용자가 엑셀 파일을 업로드하여 결재 문서 생성에 필요한 데이터를 제공합니다. `data_processing.py` 파일에서 엑셀 파일 읽기 및 데이터 처리를 담당합니다.
* **네이버 웍스 API 연동 결재 문서 생성:** 네이버 웍스 API를 활용하여 결재 문서를 자동으로 생성합니다. `workAPI_processing.py` 파일에서 JWT 생성, OAuth2 토큰 요청, 결재 문서 생성 등의 기능을 수행합니다.
* **실시간 승인 상태 추적:** 네이버 웍스 API와 REST API 서버를 통해 결재 문서의 실시간 승인 상태를 추적합니다. `workAPI_processing.py` 파일에서 승인 상태 확인을 처리합니다.
* **사내 REST 서버를 통한 승인 결과 수신:** 네이버 웍스와 ERP 사이에 위치한 REST API 서버를 통해 승인 결과를 수신합니다. `workAPI_processing.py` 파일에서 REST API 서버와의 통신을 처리합니다.
* **Oracle DB 업데이트 자동화:** 결재 문서가 최종 승인되면, REST API 서버를 통해 Oracle DB에 ERP 데이터를 자동으로 업데이트합니다. `data_processing.py` 파일에서 Oracle DB와의 연동을 통해 ERP 데이터를 업데이트합니다.
* **사용자 인증 및 세션 관리:** 사용자 인증 및 세션 관리를 통해 시스템의 보안을 강화합니다. `login.py` 파일에서 사용자 로그인 및 인증 기능을 제공합니다.
* **기초데이터 다운로드:** `data_processing.py` 파일에서 Oracle DB에서 기초데이터를 조회하여 엑셀 파일로 다운로드 합니다.
* **데이터 로드:** `data_processing.py` 파일에서 엑셀 파일에서 데이터를 로드하여, 데이터 검증 및 가공을 합니다.

## 4. 핵심 기술 스택

* **Python:** 응용프로그램 개발의 주요 언어로 사용됩니다. `costgenerator.py`, `workAPI_processing.py`, `data_processing.py`, `login.py`, `dataObject.py` 등에서 사용됩니다.
* **PySide6 (GUI):** 사용자 인터페이스(UI)를 구축하는 데 사용됩니다. `costgenerator.py` 파일에서 UI를 구성하고, `ui_main.py` 파일에서 UI 레이아웃을 정의합니다.
* **Pandas:** 엑셀 데이터 처리 및 분석에 사용됩니다. `data_processing.py` 파일에서 엑셀 파일 읽기 및 데이터 처리에 사용됩니다.
* **OpenPyXL:** 엑셀 파일 읽기 및 쓰기에 사용됩니다. `data_processing.py` 파일에서 엑셀 파일 저장에 사용됩니다.
* **Oracle DB:** ERP 데이터 저장을 위한 데이터베이스로 사용됩니다. `data_processing.py` 파일에서 Oracle DB와의 연동을 처리합니다.
* **C# .NET API (REST):** 네이버 웍스와 ERP 사이의 데이터 연동을 위한 REST API 서버를 구축하는 데 사용됩니다. `workAPI_processing.py` 파일에서 REST API 서버와의 통신을 처리합니다.
* **JWT(JSON Web Token):** 네이버 웍스 API 연동을 위한 인증에 사용됩니다. `workAPI_processing.py` 파일에서 JWT 생성 및 관리를 처리합니다.
* **OAuth2:** 네이버 웍스 API 연동을 위한 인증 프로토콜로 사용됩니다. `workAPI_processing.py` 파일에서 OAuth2 토큰 요청 및 관리를 처리합니다.
* **cryptography:** JWT 생성을 위한 암호화 라이브러리로 사용됩니다. `workAPI_processing.py` 파일에서 사용됩니다.

## 5. 업무 흐름 요약

1. 사용자가 `login.py`를 통해 로그인합니다.
2. 사용자가 엑셀 파일을 응용프로그램(`costgenerator.py`)에 업로드합니다.
3. 응용프로그램은 업로드된 데이터를 검증하고, 필요한 경우 ERP 데이터를 자동 계산합니다. `data_processing.py` 파일에서 데이터 검증 및 가공을 처리합니다.
4. 응용프로그램은 네이버 웍스에 결재 문서 생성 요청을 보냅니다. `workAPI_processing.py` 파일에서 JWT 생성 및 OAuth2 토큰 요청을 통해 API 연동을 처리합니다.
5. 네이버 웍스는 결재 문서 ID를 반환합니다.
6. 응용프로그램은 네이버 웍스에 결재 문서를 생성합니다. `workAPI_processing.py` 파일에서 결재 문서 생성을 처리합니다.
7. 응용프로그램은 네이버 웍스와 REST API 서버를 통해 결재 문서의 승인 상태를 주기적으로 확인합니다. `workAPI_processing.py` 파일에서 승인 상태 확인을 처리합니다.
8. 결재 문서가 최종 승인되면, REST API 서버는 ERP 데이터를 업데이트합니다. `data_processing.py` 파일에서 Oracle DB에 ERP 데이터를 업데이트합니다.
9. 사용자는 `costgenerator.py`에서 기초데이터를 다운로드 할 수 있습니다.
10. 사용자는 `costgenerator.py`에서 엑셀파일을 로드하여, 데이터를 가공할 수 있습니다.

## 6. 보안 고려 사항

* **사용자 인증:** 암호화된 자격 증명 저장 (`login.py`)
* **API 통신:** HTTPS 전송 (`workAPI_processing.py`)
* **세션 관리:** JWT 토큰 기반 인증 (`workAPI_processing.py`)

## 7. 향후 개선 사항

* **다단계 승인 프로세스 지원:** 복잡한 결재 프로세스를 지원하기 위해 다단계 승인 기능을 추가합니다.
* **ERP 시스템 API 직접 연동:** REST API 서버를 거치지 않고 ERP 시스템과 직접 연동하여 데이터 처리 속도를 향상시킵니다.

## 8. 특이사항

* 네이버웍스, ERP, REST API 서버와 연동이 필요합니다.
* 네이버 웍스 경영지원 API를 사용합니다.
* API를 이용하여 Response DATA로 ERP 데이터 등록을 합니다.
* `workAPI_processing.py` 파일에서 JWT 생성 및 OAuth2 토큰 요청을 통해 네이버 웍스 API 연동을 처리합니다.
* `data_processing.py` 파일에서 Oracle DB와의 연동을 통해 ERP 데이터를 조회하고 업데이트합니다.
* `login.py` 파일에서 사용자 로그인 및 인증 기능을 제공합니다.
* `costgenerator.py` 파일에서 사용자 인터페이스(UI)를 구성하고, 엑셀 파일 업로드 및 데이터 처리를 제공합니다.
* `dataObject.py` 파일에서 결재 문서 생성에 필요한 데이터 객체를 정의합니다.
* `ui_main.py` 파일에서 UI 레이아웃을 정의합니다.

## 10. 개선 효과

본 프로젝트의 목표를 성공적으로 수행했을 때, 사용자, 경영층, 협조부서의 3가지 입장에서 다음과 같은 개선 효과를 기대할 수 있습니다.

### 10.1. 사용자 (입력 실무 담당자)

* **업무 시간 단축:** 엑셀 파일 업로드만으로 결재 문서 생성이 자동화되어, 수작업으로 진행하던 결재 문서 작성 시간을 대폭 단축할 수 있습니다.
* **데이터 입력 오류 감소:** 수작업으로 인한 데이터 입력 오류를 최소화하고, 자동화된 데이터 검증을 통해 데이터 정확성을 향상시킬 수 있습니다.
* **업무 편의성 향상:** 복잡한 결재 문서 작성 및 승인 프로세스를 간소화하여, 사용자의 업무 편의성을 크게 향상시킬 수 있습니다.
* **실시간 승인 상태 확인:** 네이버 웍스와 연동되어 실시간으로 결재 문서의 승인 상태를 확인할 수 있어, 업무 진행 상황을 명확하게 파악할 수 있습니다.
* **기초데이터 활용:** 기초데이터 다운로드 및 엑셀파일 로드 기능을 통해, 데이터를 활용한 업무를 효율적으로 진행할 수 있습니다.

### 10.2. 경영층

* **업무 효율성 증대:** 결재 문서 작성 및 승인 프로세스 자동화를 통해 전반적인 업무 효율성을 크게 향상시킬 수 있습니다.
* **비용 절감:** 수작업으로 인한 인적 자원 소모를 줄이고, 업무 처리 시간 단축을 통해 비용 절감 효과를 기대할 수 있습니다.
* **데이터 기반 의사 결정:** ERP 데이터와의 연동을 통해, 정확하고 신뢰성 있는 데이터를 기반으로 의사 결정을 내릴 수 있습니다.
* **투명성 확보:** 결재 프로세스의 자동화 및 실시간 승인 상태 추적을 통해, 업무 처리 과정의 투명성을 확보할 수 있습니다.

### 10.3. 협조 부서 (ERP 관련 유관부서, 전산 ERP/ 네이버웍스 관리부서)

* **업무 부담 감소:** 결재 문서 생성 및 승인 프로세스 자동화를 통해, 협조 부서의 업무 부담을 줄일 수 있습니다.
* **데이터 연동 효율성 증대:** ERP 시스템과의 데이터 연동을 통해, 데이터 공유 및 활용의 효율성을 높일 수 있습니다.
* **시스템 관리 용이성 향상:** 자동화된 시스템 구축을 통해, 시스템 관리 및 유지 보수의 용이성을 향상시킬 수 있습니다.
* **데이터 정확성 향상:** 데이터 검증 및 자동화된 업데이트를 통해 데이터 정확성을 향상시킬 수 있습니다.
